# 2秒ドリル

場面を聞いて、**2〜3秒の無音のあいだに短い英語を声に出す**ための毎日5分のドリル。

会話の返しは普通0.2秒で始まる。一方、人が言語を産出するには0.6秒以上かかる。
つまり「聞き終わってから考える」設計では原理的に間に合わない。
このドリルが鍛えるのは語彙でも流暢さでもなく、**出だしの速さ**だけ。

## 仕組み

```
「犬を可愛いと言われた」   ← 端末が日本語で読み上げる
　（無音 3秒）            ← ここであなたが声に出す
「Yeah, she is!」         ← 答え合わせ
　（無音 1秒）→ 次へ
```

20型で約4分。読み上げは端末の機能（Web Speech API）を使うので、
**自分で音源を録る必要がなく、通信もアカウントも要らない。**

## デッキ

| | 読み上げ | 中身 |
|---|---|---|
| 20の型 | 日本語 | 時間を買う／意味が取れない／褒められた／相手に返す／道を聞かれた／店／出口 |
| 崩れた入力 | 英語 | 相手の非標準な英語（`How do you think?` など）への返し |
| 会話：注文する | 英語 | 店員のセリフが来るので、客として返す。後半は同じ場面で言い方を変えてある |

型はアプリ内で足す・消すができる。JSON で書き出し／読み込みも可能。

## 決まり

- **言えなくても止めない。** 止めると「考える」練習になってしまう
- 型は**できるだけ短く（2〜4語）**。短い型は、言っている間に考える時間が生まれる
- `No, no` で褒めを否定しない。英語では相手の判断を否定する行為になる

## 作り

単一ファイルの PWA。`index.html` だけで動く。ビルド不要。
型と記録は端末の localStorage にのみ残り、外には出ない。

| ファイル | |
|---|---|
| `index.html` | アプリ本体 |
| `sw.js` | オフライン用 |
| `manifest.webmanifest` / `icon.png` | ホーム画面に置くため |

静的ホスティングにそのまま置ける（Cloudflare Pages など）。
